My personal portfolio site built with Next.js 16 and React 19. Showcases my projects, skills, and work experience.

🔗 **Live site:** [amzil.dev](https://www.amzil.dev)

---

## Tech Stack

| Layer | Tools |
|---|---|
| Framework | Next.js 16 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS, tailwind-merge, tailwindcss-animate |
| Animations | Framer Motion |
| Theming | next-themes (dark / light mode) |
| Icons | Lucide React |

---

## Features

- ⚡ Next.js App Router with server components
- 🌙 Dark / light mode with system preference detection
- 🎞️ Smooth page and element animations via Framer Motion
- 📱 Fully responsive layout
- ♿ Accessible markup and semantic HTML
